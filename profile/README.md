# Open Picture Intelligence

Open Picture Intelligence (OPI) is an open format for media intelligence.

A .opi sidecar travels beside the media it describes. It carries
machine-produced metadata, provenance, signatures, and human annotations in a
file the media owner can keep, inspect, and move between tools.

## What OPI is

- **Open** — a published format and permissive reference implementation.
- **Signed** — producer runs can be attributed and verified.
- **Media-bound** — the sidecar records the media binding without modifying the
  master.

OPI is not a MAM, NLE, hosted AI service, or replacement for editorial
judgment. It is a file format and interoperability layer.

## Project status

OPI is early and pre-freeze. The v0 format and reference implementation are
evolving; fields and producer coverage may change. Read the current status and
specification before using it in production.
